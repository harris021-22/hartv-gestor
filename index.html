🔥 Publicar Regras no Firebase

✅ Conta liberada neste aparelho!
Para que a aprovação alcance automaticamente os celulares dos outros usuários, falta apenas publicar a regra no Console do Firebase (1 minuto).

Passo a passo rápido:

  1. Clique no botão "📋 Copiar Regras" abaixo.
  2. Clique em "🔗 Abrir Firebase Console".
  3. Cole no editor e clique no botão azul "Publicar" (Publish).
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /system_accounts/{document=**} { allow read, write: if true; } match /users/{userId}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
